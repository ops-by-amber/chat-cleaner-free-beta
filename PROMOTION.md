## Short launch post

I built **Chat Cleaner**, a free Chrome extension for selecting multiple ChatGPT conversations with checkboxes and archiving or deleting them in batches. It supports the currently loaded sidebar chats and has a stop-on-error safeguard. This is an early beta: please test on a disposable chat first. No subscription or Chrome Web Store account needed, but installation uses Chrome Developer Mode.

Download and instructions: https://github.com/ops-by-amber/chat-cleaner-free-beta

Feedback is welcome, especially about chat detection or menu failures. Please don't post private chat contents.

## Suggested early-beta goals

- First 5–10 testers successfully install and report whether one-chat Archive/Delete behaves as expected.
- Resolve any repeated menu detection bugs before broader promotion.
- Confirm feedback email forwarding after recipient activation.
- Add a clear screenshot or short demo GIF to the main README after testing on a disposable chat.
- Track downloads, useful feedback, GitHub stars and issue resolutions rather than raw followers.
