# Chat Cleaner Free Beta v1.6.0

**Free, unpacked Chrome extension.** This is a public beta, not a Chrome Web Store installation.

### Included
- Visible checkboxes beside loaded ChatGPT sidebar chats
- Title filtering and multi-select
- Sequential Archive and Delete using ChatGPT's native menus
- Safe stop if an options menu or confirmation cannot be identified
- Optional imported content/date search
- Optional quick feedback after a batch, addressed to ops.by.amber@gmail.com

### Important beta limitations
- The email feedback destination is configured through FormSubmit but **live delivery has not been verified and requires recipient activation**.
- Existing conversations must be loaded in the sidebar to be selected.
- ChatGPT interface changes can break the extension.
- “Removed from sidebar” is not server-side deletion verification.
- Deletions are permanent. Test on one disposable conversation.
- Developer Mode and Load unpacked are required; this GitHub beta does not auto-update.
